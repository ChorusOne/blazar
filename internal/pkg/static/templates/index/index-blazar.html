Notes

Internally Upgrades and Versions are separate tables. Upgrades table can be populated from different sources, most commonly from on-chain governance proposals. An on-chain upgrade is populated without a "tag", use Versions to make the upgrade pick up a tag by the matching height.

Use "Register new version" or click the "+" on the relevant upgrade line to create a version for the existing upcoming upgrade.

Use "Register new upgrade" when an on-chain upgrade does not exist. Set upgrade's Type accordingly.
